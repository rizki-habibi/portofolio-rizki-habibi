# Portofolio Rizki Habibi

Website portofolio bergaya **Sakamoto Days** untuk **Rizki Habibi** — Jurnalis Investigatif & Aktivis Digital.

## ✨ Fitur

- 🎨 Desain hitam-putih bergaya manga Sakamoto Days
- ⚡ Animasi grand: partikel canvas, glitch teks, reveal scroll, speed lines
- 📱 Responsif penuh (mobile & desktop)
- 🔢 10 seksi landing page lengkap
- 🖱️ Kursor kustom dengan efek campuran
- 🎬 Layar pembuka bergaya panel manga

## 📄 Seksi

1. **Beranda** — Hero dengan animasi reveal dan counter
2. **Tentang Saya** — Profil karakter bergaya data manga
3. **Keahlian** — Progress bar animasi per kategori
4. **Kasus Investigasi** — Timeline 2023–2025 interaktif
5. **Misi & Manifesto** — 4 misi utama & nilai filosofi
6. **Kemampuan Tempur** — Virtual & Realita dengan tab selector
7. **Kerentanan AI** — Analisis 6 platform AI tools
8. **Jadwal & Mood** — Jadwal kerja berbasis kondisi
9. **Kirim Laporan** — Form kontak terenkripsi
10. **Footer** — Navigasi & identitas

## 🚀 Teknologi

- **React 18** + **Vite 5**
- **Framer Motion 11** — animasi
- **Tailwind CSS 3** — styling
- **React Intersection Observer** — scroll trigger

## 🛠️ Jalankan Lokal

```bash
npm install
npm run dev
```

## 🌐 Deploy ke Vercel

1. Push repo ini ke GitHub
2. Import ke [vercel.com](https://vercel.com)
3. Framework: **Vite** — Build: `npm run build` — Output: `dist`
4. Deploy otomatis ✓
